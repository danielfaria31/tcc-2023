# Origem dos recursos

O código parte do projeto acadêmico de Daniel Faria e recebeu reorganização, revisão de interface e ajustes de fluxo com assistência de IA.

As imagens de produtos foram preservadas do arquivo loja_nova.rar fornecido pelo autor. O arquivo original não trouxe comprovação de licença das fotos. Marcas e imagens pertencem aos respectivos titulares; sua presença aqui não transfere direitos nem indica parceria.

Antes de usar comercialmente ou conceder uma licença sobre todo o repositório, documentar a origem/licença de cada foto ou substituí-la por imagem própria ou autorizada. Não foi aplicada licença MIT automaticamente, pois autoria e permissões de todos os recursos ainda não foram confirmadas.

Nenhum cadastro pessoal, senha do banco original, pedido ou painel administrativo foi incluído no SQL distribuído.
